Detalle del Repositorio

Endpoints del API (Ejercicio 2)

  • POST /repositories - Crear repositorio
  • GET /repositories - Listar todos
  • GET /repositories/{id} - Ver detalle
  • PUT /repositories/{id} - Actualizar
  • DELETE /repositories/{id} - Eliminar
  • GET /health - Health check

Arquitectura

  • S3: Hosting del sitio web estatico (Ejercicio 4)
  • CloudFront: CDN para distribucion global (Puntos Extra)
  • API Gateway: REST API del Ejercicio 2
  • Lambda: CRUD de repositorios (Ejercicio 2)
  • DynamoDB: Base de datos NoSQL (Ejercicio 2)
